What it does

🌐

Any site

Anything yt-dlp supports — 1,800+ sites and counting. YouTube uses its native player; every other site gets a proxied HTML5 preview.

✂️

Timeline editor

Drag to mark named regions, trim the edges, scrub to preview just that region. Export each clip as its own file.

🎧

Audio & video

Audio: MP3, WAV, AAC, M4A, FLAC, Opus, OGG. Video: MP4, MKV, WebM. Full bitrate and quality control.

📥

Chrome extension

Send the page you're on straight to the app. Corner pill for channels/playlists, hover button over videos.

🔄

Self-updating

Every 6 hours the app silently pulls the latest yt-dlp and the newest Stream Studio release. YouTube's next site change fixes itself in the background.

🖥️

Runs locally

No cloud, no account, no telemetry. Ships FFmpeg, yt-dlp and a Deno runtime bundled — nothing to install on your side.

Zero-touch, forever

1

Install

Download StreamStudio-Setup.exe. Run it. Next → Next → Finish. Auto-starts at login into the system tray.

2

Paste a link

Open http://127.0.0.1:5006 (or click the tray icon). Paste any URL. Mark clips. Pick format. Convert.

3

Never touch again

App and yt-dlp self-heal every 6 hours from GitHub and PyPI. No dialogs, no update prompts. Just works.

FAQ

Is this free?

Yes, and MIT-licensed. Source is on GitHub.

Why does SmartScreen warn me?

The installer isn't code-signed (signing costs money and I haven't done it yet). Click More info → Run anyway. Every file is bit-for-bit reproducible from the repo — you can build it yourself from BUILD.md.

Does it collect any data?

No. The app runs entirely on your machine. The only outbound calls are to PyPI (yt-dlp version check) and GitHub Releases (app version check), both public JSON endpoints. Nothing about you or what you download leaves.

Mac / Linux?

Yes — Windows 10/11 (installer), plus macOS and Linux builds on the Releases page (newer, less battle-tested). The app, yt-dlp and the Chrome extension all keep themselves up to date on every OS.

Is downloading legal?

For content you own or have the right to use — your own uploads, Creative Commons, permissioned content — yes. Downloading copyrighted material may violate a site's Terms of Service and local law. You are responsible for how you use it.
